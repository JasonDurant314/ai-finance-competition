如何复现这次运行

在项目根目录执行以下命令。无需联网、无需 API Key —— replay 完全依靠运行期间落盘的模型响应缓存：

# 1. 校验产物完整性（比对 SHA256，确认未被篡改）
python -m agent.cli verify {{ run_id }}

# 2. 离线重放并逐字节比对全部产物
python -m agent.cli replay {{ run_id }} --strict

# 3. 生成人类可读的完整审计报告（步骤时间线 + 证据链 + 校验结果）
python -m agent.cli audit {{ run_id }}
replay 的语义：在离线模式下重跑整条流水线，用缓存中的模型响应替代真实调用， 然后把每个产物的哈希与 manifest.json 中记录的原始哈希逐一比对。 缓存缺一条就会直接判定为不可复现，而不是悄悄联网重算。
